rclone Sync App

This is a personal utility application used to sync files between MEGA and Google Drive via the rclone command line tool. It is for personal use only and is not distributed to the public.

Privacy Policy

This application accesses Google Drive solely to read and write files at the direction of the account owner, for personal file syncing purposes. No data is collected, stored, or shared with any third party. All file transfers occur directly between the user's own MEGA account and their own Google Drive account.
